## Bugs fixed (from initial gap analysis)

- **B1, B2** — Vapi webhook idempotency + signature verification. `/api/vapi/webhook` now requires `x-vapi-signature` (HMAC-SHA256 with `VAPI_WEBHOOK_SECRET`); duplicate deliveries upsert by `vapiCallId` (unique index in `20260429120000`).
- **B3** — Trial expiry transitions: `trialExpiryWorker` flips `TRIAL → PAST_DUE` and emits `trialExpiry` email.
- **B4** — Removed all fallback JWT secrets. `requireEnv()` in `lib/env.ts` throws at boot if `NEXTAUTH_SECRET`, `PLATFORM_JWT_SECRET`, or any required value is missing.
- **B5** — Vapi calls are fire-and-forget. `enqueueCampaignCalls` enqueues to BullMQ and returns immediately; no setTimeout/poll loop in route or worker.
- **B6** — Removed hardcoded fallback prompt; tenant-supplied prompt is required (or fails loud).
- **B7** — Vapi error logs redact API keys, phone numbers, and call payloads through structured pino redaction.
- **B8** — Gemini service throws on empty / malformed responses (no dummy "qualified" fallback).
- **B11** — JWT revocation via `User.tokenVersion`. `requireAuth` rejects JWTs whose `tokenVersion` is older than the user's current value (password reset / forced sign-out bumps it).
- **B12** — `vapiCallId` deduplication script (`backend/scripts/dedup-vapi-call-ids.ts`) + unique index in `20260429120000`.

## Model B + PAYG (Phase 5, Agents M1–M7)

Self-service Pay-As-You-Go billing on top of a hosted (platform-owned) Vapi/Gemini/Places stack. Replaces the seat-quota subscription model for new signups; subscription tier is dormant but wired. BYOK becomes admin-only.

### New schema models / enums

- `TenantProvisioning` — per-org row tracking the hosted-stack provisioning state (`PENDING | RUNNING | READY | FAILED`), the assigned `vapiPhoneE164`, the `defaultPaymentMethodId`, and per-step progress.
- `CreditLedger` — per-org PAYG balance, lifetime totals, auto-recharge config (`autoRechargeEnabled / autoRechargeThresholdCents / autoRechargeAmountCents`), `lastAutoRechargeAt`, and `lowBalanceAlertSentAt` (24h debounce for the M7 alert engine).
- `CreditTransaction` — append-only ledger entries (`TOPUP / TOPUP_AUTO / DEBIT_CALL / DEBIT_QUALIFICATION / DEBIT_DISCOVERY / DEBIT_EMAIL / REFUND / ADJUSTMENT`). Signed `amountCents`, snapshot `balanceAfterCents`, FK `ledgerId` + `organizationId`.
- `enum BillingMode { PAYG | SUBSCRIPTION | BYOK }` on `Organization` — default `PAYG`. Tenant routes refuse any payload containing `billingMode`; only the platform endpoint can flip it.
- `enum ProvisioningStatus { PENDING | RUNNING | READY | FAILED }`.
- `OrgStatus.PAUSED_NO_CREDIT` — recoverable hard-stop fired when a debit drains the ledger to zero. Auto-flips back to `ACTIVE` on the next successful TOPUP webhook.

### Billing flow

- **Top-up**: `POST /credits/topup` triggers `chargeTopUp` which creates a Stripe PaymentIntent. The `payment_intent.succeeded` webhook (kind=`PAYG_TOPUP`) upserts CreditLedger, inserts a `TOPUP` row, and (if the org was in `PAUSED_NO_CREDIT`) flips status back to `ACTIVE`.
- **Debit**: `debitWithMarkup` runs an atomic `prisma.$transaction` that applies `PAYG_MARKUP_PCT`, decrements `balanceCents`, and inserts a signed `CreditTransaction`. Throws `InsufficientCreditsError` (HTTP 402) on overdraft. Skipped silently for `BYOK` / `SUBSCRIPTION` orgs.
- **Auto-recharge** (`maybeAutoRecharge`, fire-and-forget after every debit): if balance is at or below threshold, auto-recharge is enabled, payment method is on file, and the 5-minute debounce window has passed, fires `chargeTopUp(source="AUTO_RECHARGE")` with day-bucket idempotency key `auto-<orgId>-YYYY-MM-DD`. Card decline disables auto-recharge, emails the admin, and audits `AUTO_RECHARGE_FAILED`.
- **Low-balance alert** (`maybeSendLowBalanceAlert`, M7, fire-and-forget after every debit): silent when balance is above threshold, auto-recharge is enabled (auto-recharge owns comms), or last alert was within 24h. Otherwise sends a one-shot informational email and stamps `lowBalanceAlertSentAt`.
- **Pre-flight credit check** (campaign launch): rejects start if balance is less than 1.5x estimated lead cost.
- **Reconciliation**: `reconcileCallCost` issues an `ADJUSTMENT` (refund) or extra `DEBIT_CALL` row when actual Vapi cost differs from the pre-deduction.

### Brand-scrub policy + CI guard

Tenant-facing surfaces (`frontend/src/app`, `frontend/src/components`, `backend/src/emails`) must never reference vendor names (Vapi / Twilio / Gemini / Google Places / Resend / OpenAI / Bland / Deepgram / ElevenLabs). Admin app is exempt - admins see real vendor names.

`backend/src/services/provisioning/brandScrub.ts` exports `scrubBrandStrings()` and `scrubError()` for runtime defence-in-depth on dynamic strings (e.g. `TenantProvisioning.failureReason`).
